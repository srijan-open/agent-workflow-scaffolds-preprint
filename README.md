# When Do Agent Scaffolds Actually Help?

**Toward Compute-Normalized Evaluation of Workflow-Guided LLM Agents**

Srijan Choudhary · Error6o6 Labs · 27 July 2026

This repository is the public archival home for a measurement-agenda preprint and its pilot harness evidence. It is **not** presented as a fully powered empirical benchmark.

## Abstract

We develop a measurement agenda for testing when workflow scaffolds improve LLM-agent reliability under matched compute budgets. The paper proposes regime-based comparisons between unstructured, repeated-unstructured, plan-first, and plan-plus-check workflows, accompanied by call-accounted pilot evidence and explicit limitations.
